## 一、产品监控（销量监控）

### 支持站点

美国、日本、英国、德国、法国、意大利、西班牙、加拿大、印度（共 **9 站**）。

### 额度（主账号与子账号**共享**）

| 套餐 | 产品监控 | 关键词监控 | 店铺上新监控 |
|---|---|---|---|
| 包月套餐 | 100 个 | 500 个 | 50 个 |
| 标准包年套餐 | 100 个 | 500 个 | 50 个 |
| 高级包年套餐 | 300 个 | 1000 个 | 100 个 |
| VIP 包年套餐 | 500 个 | 2000 个 | 200 个 |
| 免费会员 | 无额度 | 无额度 | 无额度 |

> ⚠️ 主账号与子账号**共享监控额度，不能指定分配**。任一端超额会影响整体。可在【产品监控】-【监控操作中心】查看已用/总额度。

### 监控内容与更新

- 每 **24 小时**更新一次；
- 可监控：**BSR 排名、价格、评论数**及其他表现变化。

### 销量计算原理（必须理解）

```
今日销量 = 昨日库存 − 今日库存
```

因此必须**监控两天左右**才会出现销量数据（新添加产品需等约 24h 才有变化值）。

**被排除的情形**（受亚马逊购物车限制，计算销量时会排除）：
1. 卖家限制单次购买数量（如最多购买 9 件）；
2. BuyBox 拥有者发生变化；
3. 当次库存比前一次多（补货、退货等）；
4. 商品发货类型变化（自发货 ↔ FBA）；
5. 商品库存 > 999。

**为什么与其他软件数字不同？** 原理相同，只是**采样时间点不同**（卖家精灵约每天下午 17 点采样，其他软件可能上午 9 点），24 小时内的库存差值就会不同。
> **建议不要纠结某天的销量，主要看整体趋势**，特别是库存、销量的变化趋势。

### 常见问题

| 问题 | 原因 |
|---|---|
| 添加了产品却没有数据 | 新添加需等 24h 后才有各维度变化值，各指标每天更新一次 |
| 添加失败 / 无销量 | 可能添加的不是子体（**父体目前无法监控**）；或选错国家（想监控英国站却选了美国站） |
| 能否一次监控所有变体 | 暂不支持，建议**批量添加**所有变体 ASIN |
| 分组名怎么改 | 点分组命名即可修改 |

### 使用场景

- 跟踪核心竞品价格变化；
- 观察竞品评论增长速度；
- 判断竞品排名是否稳定；
- 监控新品或潜力产品的后续表现；
- 及时发现竞争对手的运营动作。

> 添加方式：在选产品 / 查竞品结果中，点产品右侧的**关注按钮**。

## 二、关键词监控

### 定位

监控**自己 Listing 的优化与推广效果**，是关键词五部曲中的一环：

```
1. 关键词搜集 → 2. 关键词整理 → 3. 关键词优化（植入 Listing/QA/Review）
→ 4. 关键词提升（PPC、定向引流、销量） → 5. 关键词效果评估
```

也可以监控同类产品的关键词提升过程，但一般通过**关键词收录**来监控。

### 添加监控

1. 点加号或操作列的「操作中心」图标；
2. 在右侧输入框添加该 ASIN 下需要监控的关键词（**可一次性复制粘贴多行**，如从关键词反查导出的表）；
3. 点【保存关键词】开启监控。

新添加关键词的排名数据**几分钟内**展示，包括：关键词搜索结果数、排名趋势、绝对排名、页码排名、排名变化。**数据从监控日开始每日更新。**

### 查看已监控关键词

在关键词监控页点关键词监控栏下的数字，或产品最右操作栏 →【查看监控产品历史】→【关键词监控】。

支持**图形**与**列表**两种形式：
- **图形**：各关键词一种颜色，直观对比近 **30 天 / 60 天**数据；
- **列表**：可**批量终止 / 恢复 / 删除**关键词监控。被终止的关键词不会被剔除，只是处于**未激活**状态，可选定后点【批量恢复】重新查看。

### 更新频率

- 数据每天更新一次，采取**滚动更新**，各 ASIN 具体更新时间点不固定；
- 初次监控 **24h–48h** 更新一次。

**为什么与前台实时排名不一致？**
关键词监控每天更新一次且时间点不固定；而亚马逊前台排名实时更新，且**不同查询 IP 的搜索结果会不同**。因此不同时间段采集的数据**不一定与当前实时查询 100% 吻合**。

## 三、店铺上新监控

- 数据全部抓取自亚马逊前台，**一天更新一次**；
- 可掌握店铺动向：产品上新频率、产品类型变化、产品所在类目、店铺重点布局方向；
- 用于判断竞争对手是做**精品、铺货、高端产品还是大众化产品**。

> 与**查竞品-卖家名称查询**配合使用：后者看当前产品结构，店铺监控看**动态变化**。

---

## 四、监控类功能使用纪律

1. **额度先确认**：监控额度共享且不可分配，添加前先看【监控操作中心】的已用/总额度，避免占用他人额度。
2. **看趋势不看单点**：销量为库存差估算，受补货/退货/限购影响；排名受 IP 与采集时点影响。
3. **关键词监控优先用于验证自己的优化动作**：调整 Listing 或广告后，用排名趋势验证效果。
4. **监控 ≠ 实时**：产品监控 24h 一次，关键词监控滚动更新，店铺监控每日一次。给出结论时必须说明数据时效。
