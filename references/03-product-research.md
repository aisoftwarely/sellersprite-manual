# 03 · 选产品 与 查竞品（产品调研）

> 官方快速入门：选产品 <https://www.sellersprite.com/cn/help/product-research-for-beginners> ｜ 查竞品 <https://www.sellersprite.com/v3/knowledge/feature/competitor-lookup-for-beginners>
> 功能入口：选产品 `/v3/product-research` ｜ 查竞品 `/v3/competitor-lookup`

## 一、选产品（Product Research）

### 定位

**微观选品**：按月销量、月销量增长率、评论数、评分、价格、上架时间、配送方式等条件，从具体产品维度判断某个 ASIN 是否值得研究。

适合场景：没有明确选品方向、或已有大致方向但需筛具体产品。可解决的问题：

1. 不知道选什么产品，先从系统推荐模式找机会；
2. 发现短期销量增长较快的产品；
3. 找销量不高但正在增长、上架时间短的潜力新品；
4. 找销量不错但评分较低、有改进空间的产品；
5. 筛以 FBM 自发货为主、库存压力较低的产品；
6. 观察卖家数量较多、需求较明显的产品；
7. 按预算与经验自定义筛选；
8. 对结果继续做历史数据、市场分析、产品对比、监控或批量导出。

### 推荐选品模式（系统预设筛选条件）

| 模式 | 预设条件 | 适合人群 / 用途 |
|---|---|---|
| 销量飙升榜 | 月销量 > 300；月销量增长率 > 10% | 捕捉短期需求变化（季节、节日、热点、新品爆发） |
| 潜力市场 | 月销量 < 600；增长率 > 10%；近半年上架 | 贸易型中小卖家；判断「正在增长且还有进入空间」 |
| 未被满足的市场 | 月销量 > 300；评分 < 3.7 | 有产品改造能力的工厂型卖家，做升级款 |
| 不压库存的市场 | 月销量 > 300；近半年上架；配送方式 FBM | 想降低库存压力、练手零库存转卖 |
| 投机市场 | 月销量 > 600；卖家数 > 3 | 观察需求与通用款流量分布（**不建议盲目跟卖**） |
| 新手推荐 | 月销量 > 300；增长率 > 3%；$15–60；近 1 年；FBA | 新手快速起步 |

**自定义选品示例**（中小卖家，预算不高，希望有销量、价格适中、短期能起）：
月销量 > 500；月销量增长率 > 10.0%；评论数 < 50；价格 `$10–30`；近半年上架。
→ 有销量基础 + 近期增长明显 + 评论壁垒低 + 价格适中。

可点【保存当前模式】存入【我的模式】复用。

### 组合思路

把**潜力市场**与**未被满足的市场**结合，找「刚起步但仍有改进空间」的产品：上架时间短、月销量在增长、评论数不高、评分不理想、有明确可优化点。

### 结果解读要点

**销量飙升榜的陷阱**：销量飙升可能来自季节性、节日、短期热点或突发需求。必须看历史销量趋势：
- 每年同一时间段飙升 → 偏季节性/节日性，需提前规划备货与推广节奏；
- 过去平稳、近期突然增长 → 可能是潜力产品/新需求。

**未被满足的市场的分析步骤**：
1. 筛出高销量 + 低评分产品；
2. 查评论，重点看差评与中评；
3. 总结买家集中反馈的问题；
4. 判断这些问题能否通过产品改造解决；
5. 结合供应链能力，评估是否值得开发升级款。

**投机市场的必查项**：是否通用款、有无品牌/商标/专利/版权风险、跟卖卖家是否过多、价格竞争是否激烈、是否还有差异化空间。
⚠️ **不要跟卖专利产品与品牌产品**，避免侵权与账号风险。

### 辅助功能

| 功能 | 用法 |
|---|---|
| 列表模式 / 大图模式 | 列表看数据对比；大图看外观、款式、颜色、设计、使用场景 |
| 查看 ASIN 历史数据 | 点右侧历史趋势图标，看近 **2 年**：销量趋势、子体销量趋势、历史趋势、留评率、核心关键词趋势 |
| 自定义品类 | 勾选产品加入，用于集中分析 / 建样本池 |
| 市场分析 | 点产品下方按钮，跳转选市场分析所属类目 |
| 产品对比 | 勾选 2–5 个产品，横向比销量、价格、BSR 等 |
| 流量词对比 / 拓展流量词 | 比关键词覆盖差异，补充词库 |
| 产品监控 | 点右侧关注按钮，每 24h 更新 BSR/价格/评论数等 |
| 批量导出 | 支持批量导出数据，用于离线分析、协作、存档 |

**历史数据怎么读**：

| 现象 | 可能含义 |
|---|---|
| 销量长期稳定 | 有持续需求 |
| 销量只在某几个月突升 | 季节性 / 短期活动影响 |
| 价格长期下降 | 竞争加剧 |
| 评论持续增长 | 仍在稳定出单 |
| BSR 排名波动大 | 需结合销量趋势判断真实表现 |

## 二、查竞品（Competitor Lookup）

### 定位

快速了解竞品的**销量表现、BSR 排名、价格、评论、评分、品牌、卖家和类目分布**。支持四种查询方式。

**数据覆盖**：每月更新亚马逊各站点站内大类 BSR **10 万以内**的 ASIN；其中**美国站覆盖大类排名 30 万以内**。

### 四种查询方式

| 查询方式 | 适用场景 | 关键用法 |
|---|---|---|
| **ASIN 查询** | 已知竞品 ASIN，查销量/排名/价格/评论 | 一次最多 **1000 个 ASIN**；勾选「包含变体」可同时查其他变体 |
| **关键词查询** | 想开发新品类 / 看某关键词下哪些产品受欢迎 | 输入关键词后按月销量降序，看热销款式 |
| **品牌名称查询** | 研究头部品牌的产品布局与销售表现 | 如查 `sony` 看其类目覆盖、产品线、主要销量来源、价格带 |
| **卖家名称查询** | 研究竞争对手店铺的产品结构 | 判断精品 vs 铺货、爆款/引流款/利润款、是否持续上新 |

**关键词查询结果重点看**：
1. 月销量较高的产品 → 市场主流需求；
2. 评论数较少但销量较好的产品 → 潜在机会；
3. 价格区间分布 → 市场定价带；
4. 产品款式与卖点 → 买家偏好；
5. 类目分布 → 主要落在哪些细分类目。

> 关键词查询不仅能看「谁卖得好」，也能帮判断「为什么卖得好」。

**品牌查询 vs 卖家查询**：品牌查询关注「品牌怎么做」，卖家查询关注「店铺怎么卖」。想持续跟踪某卖家动态，配合**店铺监控**使用（上新频率、产品类型变化、所在类目、布局方向）。

### 辅助功能

与选产品基本一致：列表/大图模式、ASIN 历史数据（近 2 年）、自定义品类、市场分析跳转、产品对比（2–5 个）、流量词对比、拓展流量词、产品监控、批量导出。

### 导出规则（重要）

| 导出类型 | 规则 |
|---|---|
| 导出（列表） | 默认仅前 **2000** 条；闲时（**19:00–次日 08:00**）可导前 **3000** 条；可自定义勾选 ASIN；可勾选「导出主图」；付费会员每天 **50 次** |
| 导出明细 | 批量导出所选产品的**历史月销量与历史月销售额**；一次最多 **100** 个 ASIN；付费会员每天 50 次 |

> 建议**先过滤和排序**，让结果更精准后再导出。

## 三、产品调研标准作业顺序

```
选市场定方向
   ↓
选产品（推荐模式 → 自定义）筛候选 ASIN
   ↓
查历史趋势（2 年销量/留评率/核心词）判断稳定性与季节性
   ↓
查竞品（关键词/品牌/卖家）交叉验证竞争格局
   ↓
产品对比（2–5 个）横向比销量·价格·BSR
   ↓
1688 / Alibaba 找同款货源 + 利润计算器算净利与利润率
   ↓
加入产品监控持续跟踪
```

## 四、高频问题

**Q：选产品和选市场先用哪个？**
A：两种都行。有目标类目 → 先选市场判断市场，再选产品筛具体产品；没有明确方向 → 先选产品发现 ASIN，再选市场分析其类目。

**Q：销量飙升的产品一定值得做吗？**
A：不一定。需结合历史销量趋势、价格变化、评论增长、供应链能力与竞争情况综合判断。

**Q：不压库存的市场是否风险更低？**
A：不是。主要指以 FBM 自发货为主、库存压力可能较低，但仍需评估采购成本、物流成本、交付时效、售后风险和平台规则。

**Q：产品监控多久更新？**
A：每 **24 小时**更新一次，支持监控 BSR 排名、价格、评论数及其他表现变化。新加入的产品需等待约 24h 才有变化值。
