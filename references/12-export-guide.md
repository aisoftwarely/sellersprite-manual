# 12 · 导出指南：「导出」与「导出明细」到底选哪个

> 这是实操中最高频的困惑点。选错按钮要么拿不到想要的字段，要么白耗配额。
> 本文给出判断标准、配额机制、各模块规则与省配额技巧。

## 一、一句话结论

| 按钮 | 本质 | 数据形态 | 上限逻辑 |
|---|---|---|---|
| **导出** | 导**当前列表这一批**数据（快照） | **宽表**：一行一个关键词/产品，含当前各字段 | 受**行数**限制（2000 / 闲时 3000） |
| **导出明细** | 导**你勾选的那几个对象的历史时间序列** | **长表**：一行一个「对象 × 月份」 | 受**对象个数**限制（关键词 ≤ 50 / ASIN ≤ 100） |

**一句话记忆**：
- 要「**现在这份榜单**」→ 点【导出】
- 要「**这几个词/产品过去几年的走势**」→ 点【导出明细】

## 二、界面提示原文（官方 tooltip）

**【导出】**
> 支持快速导出前 2000 条，也可以自定义勾选关键词导出（当天剩余 49 次）
> 由于数据量大，导出变体与前 3 产品图只能选一个哦！
> ☐ 导出变体　☐ 导出前 3 产品图

**【导出明细】**
> 批量导出所选关键词的历史明细，一次最多可导出 50 个关键词（当天剩余 50 次）

> ⚠️ 注意两个 tooltip 里的**计数是分开的**（一个显示 49 次、一个显示 50 次）——说明
> **【导出】与【导出明细】各自独立计次，互不占用**。

## 三、决策表：按你的目的选

| 你想拿到什么 | 选哪个 | 说明 |
|---|---|---|
| 某个关键词下前 2000 个流量词/搜索结果 | **导出** | 快速导出，无需勾选 |
| 我只想要列表里勾中的这几十个词 | **导出** | 勾选后用「自定义勾选关键词导出」 |
| 竞品的**历史月销量 + 历史月销售额** | **导出明细** | 查竞品模块，一次最多 100 个 ASIN |
| 某几个关键词**近 3 年各月**的搜索量/排名 | **导出明细** | 关键词模块，一次最多 50 个关键词 |
| 某个 ASIN **历史累计的全部关键词** | **关键词反查 →【历史全量关键词导出】** | 这是独立入口，不是普通导出 |
| 批量拓词（多 ASIN）的合并去重结果 | **导出** | 拓展流量词模块 |
| 产品列表 + 主图 | **导出**（勾「导出主图」/「导出前 3 产品图」） | 见下方勾选项说明 |

## 四、导出弹窗的勾选项（关键词类列表）

| 勾选项 | 作用 | 什么时候选 |
|---|---|---|
| ☐ **导出变体** | 同时导出该关键词相关的变体信息 | 你要分析**多变体 Listing 的词覆盖差异**时选它 |
| ☐ **导出前 3 产品图** | 导出该关键词搜索结果前 3 名产品图片 | 你要**人工核对关键词相关性**（判断 Top10 里有没有同款）时选它 |

> ⚠️ **由于数据量大，这两个只能选一个。** 先想清楚这次导出的目的再勾。
> - 做**关键词相关性清洗** → 选「导出前 3 产品图」
> - 做**变体流量结构分析** → 选「导出变体」

## 五、各模块导出规则速查

| 模块 | 【导出】 | 【导出明细】 |
|---|---|---|
| **关键词选品** | 前 **2000** 条；闲时（19:00–次日 08:00）前 **3000** 条；可自定义勾选关键词 | 所选关键词**近 3 年各月**明细数据；一次最多 **50** 个关键词 |
| **关键词反查** | 导出反查到的流量词结果；历史累计词走独立的【历史全量关键词导出】入口 → 点【导出数据】 | 勾选关键词后导出其历史明细 |
| **拓展流量词** | 导出批量拓词合并去重后的结果 | — |
| **查竞品** | 默认前 **2000** 条；闲时可导前 **3000** 条；可自定义勾选 ASIN；可勾选「导出主图」 | 所选产品的**历史月销量 + 历史月销售额**；一次最多 **100** 个 ASIN |
| **选产品** | 支持批量导出 | — |

**统一限制**：付费会员**每天可导出 50 次**（【导出】与【导出明细】分别计次）。
**闲时时段**：晚 **19:00 – 次日 08:00**，可导前 3000 条。

## 六、关键词反查的完整导出路径（高频场景）

```
① 输入 ASIN → 立即查询
   └─ 得到「近 30 天进入搜索结果前 3 页的搜索流量词」列表

② 分流：
   ├─ 要「当前这批流量词」        → 点【导出】
   │     └─ 勾选：导出变体  或  导出前3产品图（二选一）
   │
   ├─ 要「这几个词的历史走势」     → 勾选关键词 → 点【导出明细】
   │     └─ 一次最多 50 个关键词
   │
   └─ 要「历史累计的全量关键词」   → 切换到【历史全量关键词导出】页签
         └─ 输入 ASIN → 查询 → 点【导出数据】
```

**导出后怎么用（官方推荐做法）**：
- 把导出结果与**亚马逊后台广告报表**对比 → 检查是否有**不相关关键词在持续消耗广告预算** → 及时否定；
- 把流量占比高的词按用途分库（Listing 核心词 / 长尾词 / PPC 测试词 / 竞品监控词）。

## 七、省配额与提效技巧

1. **先过滤排序再导出**。不要直接导原始几万条——先用筛选条件缩小范围，让结果更精准后再导。
2. **能等就等闲时**。19:00 之后导，行数上限从 2000 提到 3000。
3. **明细导出先精简对象**。关键词压到 ≤ 50 个、ASIN 压到 ≤ 100 个，否则会失败或需分批。
4. **两类额度分开用**。【导出】与【导出明细】独立计次，别把一个用光导致另一种也用不了。
5. **勾选项别选错**。「导出变体」与「导出前 3 产品图」只能二选一，选错要重新导，直接浪费一次配额。
6. **优先「加入词库」替代重复导出**。列表页有【加入词库】/【全部加入词库】按钮——把词先沉淀到关键词词库，后续在词库里管理，比反复导出更省事。

## 八、常见误判

| 误判 | 事实 |
|---|---|
| 「导出明细就是导出得更详细一点」 | 不是。**导出明细是历史时间序列**（多个月份），字段维度不同 |
| 「两个按钮共用 50 次额度」 | 不是。**分别计次**（tooltip 里两个计数是独立的） |
| 「导出明细可以一次导几百个词」 | 不行。**一次最多 50 个关键词**（查竞品是 100 个 ASIN） |
| 「导出变体和导出前 3 产品图都勾上」 | 不行。**只能选一个**，因为数据量大 |
| 「导出没成功是额度用完了」 | 先排查：是否超过行数上限、是否处于闲时之外、勾选项是否冲突 |
