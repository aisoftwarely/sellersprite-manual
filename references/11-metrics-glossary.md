# 11 · 指标术语表与正确解读口径

> 本文件是**防误读清单**。卖家精灵的多数指标衡量的是「覆盖广度」或「估算值」，不是实际流量与转化。
> 给用户下结论前，先核对本表。

## 一、选品与市场类指标

| 指标 | 定义 | 正确解读 | 常见误读 |
|---|---|---|---|
| 月销量 | 基于 BSR 与采样推算的估算值 | 看趋势与量级，不纠结绝对值 | 当成亚马逊官方真实销量 |
| 月销售额 | 月销量 × 售价的估算值 | 用于比较市场容量 | 当成精确财务数据 |
| 月销量增长率 | 环比/同比增幅 | 连续多月增长才具趋势意义 | 单月增长即判定为潜力品 |
| 商品集中度 | 头部商品销量占样本总销量比例 | 越高越垄断（示例 71.1% → 高度垄断） | 与「品牌集中度」混为一谈 |
| 品牌集中度 | 头部品牌维度的集中程度 | 判断品牌垄断门槛 | — |
| 卖家集中度 | 头部卖家维度的集中程度 | 判断卖家垄断程度 | — |
| 平均卖家数 | 跟卖卖家数量 | 越大 → 竞争越激烈，但机会也越大 | 单纯当作负面信号 |
| 新品数量 / 占比 | 新上架产品数量与占比 | 占比越大机会越大；**服饰等快迭代品类天然偏高** | 对所有品类套用同一标准 |
| 上架时间分布 | 按上架时长分段的销量占比 | **1 个月–1 年**占比越高 → 买家越接受新品 | — |
| 卖家类型分布 | AMZ / FBA / FBM 等类型占比 | 判断履约方式与库存压力 | FBM 就一定低风险（不是） |
| 评论数分布 / 评分值分布 | 评论与评分的分布结构 | 判断新品进入壁垒 | — |
| 类目商品数 vs 搜索结果数 | 两个不同口径 | 类目商品数 = 收录商品数；搜索结果数 = 搜索结果量 | 混用两个数字 |

## 二、关键词类指标

| 指标 | 定义 | 正确解读 | 常见误读 |
|---|---|---|---|
| 月搜索量 | 关键词月度搜索需求 | 需求规模，不能单独决策 | 搜索量大就一定值得做 |
| 月搜索量增长率 | 需求变化速度 | 连续多月增长 → 趋势可靠 | — |
| 近 3 个月增长值 | 近期新增需求规模 | 适合找潜力市场 | — |
| 商品数 | 该词下的市场供应量 | 与搜索量一起看 | 只看搜索量 |
| **供需指数** | **= 搜索量 / 商品数** | 指数越小 → 竞争可能越大；搜索量大 + 商品数少 → 机会 | 当作唯一决策依据 |
| 点击集中度 | 点击集中在少数产品的比例 | **> 70% 说明高度垄断**（示例 `meat chopper`） | — |
| 相关度 | 该词与查询词在搜索结果**第一页自然排名中同款竞品 ASIN 的比例** | 越高越相关；建议过滤 `相关度 > 5` | — |
| **SPR** | 预估关键词上首页所需单量 | 越低越容易推；升序排列找易推词 | 当作确定值 |
| 购买量 / 购买率 | 关键词带来的购买转化相关 | 长尾词常见「搜索量中等但购买率高」 | — |
| 标题密度 | 该词在标题中出现的密度 | 辅助判断竞争 | — |
| AC 标识 | Amazon's Choice 标识 | 辅助判断词的市场地位 | — |
| PPC 竞价 | 广告竞价水平 | 结合竞争强度判断 | — |
| ABA 周排名 | 亚马逊品牌分析搜索排名 | 与月搜索量结合做第一轮筛选 | — |
| 市场周期 | 关键词的季节性旺淡季分布 | 用于季节性/节日性备货排期 | — |

## 三、流量与广告类指标（**最易误读**）

| 指标 | 定义 | 正确解读 | 常见误读 |
|---|---|---|---|
| 搜索流量词 | 让 ASIN 进入亚马逊搜索结果**前 3 页**、带来搜索曝光的词 | 反映关键词覆盖 | — |
| **流量占比** | 该词带来的**曝光量**占比 | 优先关注占比高的词 | 当成转化率或订单占比 |
| 自然流量占比 | 自然搜索曝光占比 | 两者**相加可 > 100%**（同词既有自然又有广告曝光） | 认为 > 100% 是数据异常 |
| 广告流量占比 | 广告曝光占比 | 同上 | — |
| 流量词类型 | 该 ASIN 在词搜索结果中的曝光位置与推广方式 | 判断竞品重点推广词与广告类型 | — |
| **流量词数量** | 该 ASIN 覆盖的关键词数量 | **只反映覆盖广度，不能换算成流量/点击/订单** | 「自然词多于广告词 → 自然流量一定更大」 |
| 全部流量词 | 页面统计的流量词总数 | 初步比较覆盖广度 | — |
| SP 广告词 / 视频广告词 / 品牌广告词 | 各广告类型对应的词数 | 比较广告关键词覆盖 | 词多 = 该广告贡献的实际流量最高 |
| AC / ER / 4 星 / HR 推荐词 | 各推荐位的词数 | 按列看数量，点开看词表 | — |
| 搜索结果数（查流量来源） | 一段时间内进入过前 3 页的产品数量 | 越多 → 流动性越大；越少 → 越稳定、进入难度越高 | 当成某一时点的前 3 页产品数 |
| 广告搜索词 | 抓取到的实际触发广告的搜索词 | 判断竞品词根与相关性的依据 | **当成竞品后台设置的投放词** |
| 广告活动 / 广告组数量 | 抓取到的层级数量 | 同色 = 同一广告活动；多变体投放会分别展示 → 数量可能多于后台实际 | 当成竞品后台的真实广告组数 |
| 趋势图圆点 | 该周期内的**广告搜索词数量** | 圆点越大词越多 | 当成竞品广告预算 |
| 关联 ASIN 数量 | 出现过关联曝光的 Listing 数量（近 90 天） | 反映关联覆盖范围 | **当成实际访问量/订单量** |
| 免费关联流量占比 | 非广告关联位置占比 | 结合关联商品相关性一起看 | 只追求比例高低 |
| 付费关联流量占比 | 广告等付费关联位置占比 | 同上 | — |

## 四、评论类指标

| 指标 | 定义 | 正确解读 |
|---|---|---|
| 评分星级占比 | 各星级 **Rating** 数量 / 总评分数 | 与「评论星级统计」是**两个不同指标** |
| 评论星级统计 | 各星级**文字 Review** 数量 / 总评论数 | 低星文字评论占比高 → 买家能看到较多负面反馈 |
| VP 评论 | Verified Purchase 评论 | 评论类型结构的一部分 |
| 图片 / 视频评论 | 带图/带视频的评论 | 用于比较 Listing 的评论内容结构，**不能单凭此推断转化率** |
| Vine 评论 | Vine 计划评论 | — |
| 评论型号统计 | 各变体在指定时间范围内的评论数量与占比 | 辅助判断变体受欢迎程度与备货 |
| 留评率 | 评论数 / 销量 | 用于判断出单稳定性 |

⚠️ 评论数据存在**留评率与时间延迟**，且受上架时间、变体合并、促销活动影响。

## 五、账号与数据类

| 项目 | 口径 |
|---|---|
| 销量监控原理 | **今日销量 = 昨日库存 − 今日库存** |
| 被排除情形 | 限购、BuyBox 变更、库存增加（补货/退货）、发货类型变化、库存 > 999 |
| 采样时点 | 卖家精灵约**每天 17:00** 采样（其他软件可能 09:00）→ 数字不同属正常 |
| 数据更新 | 插件实时；销量每日；关键词库每月；趋势选品每周；反查每日滚动；监控每日 |
| 监控额度 | 主账号与子账号**共享，不可指定分配** |

## 六、下结论前的自检清单

在把数据写成结论之前，逐条自检：

- [ ] 这个指标衡量的是**覆盖广度**还是**实际流量/转化**？
- [ ] 数字是**估算值**还是**实测值**？（月销量、毛利率均为估算）
- [ ] 数据**时效**是否与结论匹配？（关键词库是月更，不能当实时）
- [ ] 是否有**多个指标交叉验证**，而不是单指标下结论？
- [ ] 是否存在**口径陷阱**？（自然+广告 > 100%、搜索词 ≠ 投放词、关联数 ≠ 访问量）
- [ ] 是否标注了**推测与待验证假设**？
- [ ] 是否给出了**风险项**（竞争、合规、供应链、库存、广告成本）？

> 若任一项为「否」，不要把该结论作为最终决策输出。
