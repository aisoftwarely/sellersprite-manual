# 02 · 选市场（市场调研）

> 官方快速入门：<https://www.sellersprite.com/cn/help/market-research-for-beginners>
> 功能入口：`https://www.sellersprite.com/v3/market-research`

## 一、功能定位

**选市场是供应端、宏观选品**：亚马逊的每个类目节点本质上就是一个细分市场。选市场通过比对、分析、过滤各维度指标，帮卖家选出最匹配自身定位与优势的细分市场。

主要面向**工厂型 / 品牌型卖家，以及精铺卖家**。也可用于验证——当已用其他功能初步筛出感兴趣的产品时，用它判断该产品所属细分市场是否值得进入。

> 与选产品的分工：**选市场偏宏观**（类目/市场值不值得进），**选产品偏微观**（具体 ASIN 值不值得研究）。实操中两者结合：先选市场定方向 → 再选产品筛 ASIN；或先选产品发现机会 → 再回选市场验证。

## 二、标准流程

```
筛选市场 → 分析市场 → 查看参考蓝本 → 寻找同款货源 → 利润测算
```

### 第 1 步：筛选市场

选择大类或二级类目后，挑任一数据维度对结果排序，快速定位符合自身条件的市场。

| 卖家类型 | 排序策略 | 逻辑 |
|---|---|---|
| 新手卖家 | **新品数量降序** | 新品数量占比越大 → 市场机会越大 |
| 有雄厚实力 | **月总销量降序** | 月总销量越大 → 市场容量越大 |
| 中小卖家 | **商品集中度升序** | 集中度越低 → 销量分布越分散 → 垄断度越低 |

⚠️ 例外：更新迭代快的品类（如服饰）新品占比天然很高，不断有新款式推出，新手**不建议**仅凭此进入。

叠加过滤参数缩小范围。示例（资金预算不高的中小卖家）：
- 平均价格 `$10–30`（不做单价过高的产品）
- 商品集中度 `< 50%`（避免一入场就激烈竞争）
- 按新品数量降序排列

> 结果表中每个指标后的小问号，悬浮可看该指标的详细解释。

常见指标速读：

| 指标 | 含义 |
|---|---|
| 平均卖家数 | 跟卖卖家数量。数字越大 → 竞争越激烈，但市场机会也越大 |
| 商品集中度 | 头部商品销量占样本总销量的比例，越高越垄断 |
| 品牌集中度 / 卖家集中度 | 品牌、卖家维度的集中程度 |
| 新品数量 / 占比 | 反映新品进入活跃度与机会大小 |

### 第 2 步：分析市场

点进市场分析报告，看**九大维度**：

1. 行业需求及趋势
2. 商品集中度
3. 品牌集中度
4. 卖家集中度
5. 卖家类型分布
6. 上架时间分布
7. 上架趋势分布
8. 评论数分布
9. 评分值分布

用途：对市场的**需求、垄断性、竞争难度**形成全局认识，进一步确认市场。

关键读法示例：
- **上架时间分布** → 判断新品进入难度。上架 **1 个月–1 年**的产品销量占比越高，说明买家对**新品接受程度越高**。
- **商品集中度** 高达 70%+ → 头部前 10 个产品吃掉 70%+ 销量，市场高度垄断、趋于饱和。

### 第 3 步：查看参考蓝本

在市场分析报告最上方，点链接跳到「查同类产品」页面，查看该市场 **TOP100** 商品明细。

挑选标准：**上架时间不长 + 评论数、销量趋势稳定或平稳上升**的产品 → 作为产品开发与 Listing 打造的对标产品。

### 第 4 步：利润测算

确定参考蓝本后，点产品下方「更多」按钮，一键跳转 **1688 找同款货源**；打开右侧**利润计算器**，输入各项成本，快速得出利润率。

## 三、验证市场进入的可行性

选市场也可用于**反向验证**：当已通过选产品、查同类产品、关键词选品等选好产品、需要判断市场时，通过**类目选择或类目查询**直达目标类目节点分析。

另有两个快捷入口：
- 在**查同类产品**和**选产品**页面，点产品下方「市场分析」按钮，一键直达市场分析报告；
- 用**自定义样本**做市场分析（见下）。

## 四、自定义样本市场分析

官方说明：<https://www.sellersprite.com/v3/knowledge/feature/user-defined-category-for-amazon-marketing-research>

适用场景：
- 想把多个候选产品放一起比较；
- 想分析某个细分市场的整体表现；
- 想观察同类产品的价格、销量与竞争情况；
- 想为新品开发建立参考样本池。

操作：在选产品 / 查竞品结果中勾选产品 → 加入**自定义品类** → 基于该样本生成市场分析。

## 五、高频问题

**Q：短期内查看同一细分市场，月总销量变化较大？**
A：市场样本随抓取时点变化，建议看趋势而非单次快照。详见官方说明 `/cn/help/data-differences-of-market-research`。

**Q：市场分析报告-行业趋势里的关键词看起来与产品不相关？**
A：见 `/cn/help/of-the-industry-demand-and-trend`。

**Q：类目商品数和搜索结果数有什么区别？**
A：见 `/cn/help/how-to-distinguish-total-products-from-search-results`。

**Q：为什么亚马逊前台 BSR 排行页面的类目，在选市场的类目选择里没有？**
A：卖家精灵按**产品上架类目**收录数据。当产品 BSR 类目与上架类目不一致时，用 BSR 类目会查不到数据。见 `/cn/help/product-category-of-sellersprite`。

## 六、决策纪律

- 选市场给出的是**候选市场清单**，不是最终结论。
- 判断「可进入」需同时满足：需求趋势可验证、集中度可接受、利润空间足够、供应链可支撑、无合规风险。
- 官方参考：`选市场-功能图解` PDF <https://o.sellersprite.com/docs/dl/market-research-guideline.pdf>
