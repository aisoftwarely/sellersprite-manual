# 09 · 账号、套餐、额度与数据更新

> 官方说明：子账号使用帮助 <https://www.sellersprite.com/v3/knowledge/feature/child-account-guide> ｜ 常见问题 FAQ <https://www.sellersprite.com/v3/knowledge/feature/faq-for-cs>

## 一、主账号 vs 子账号

子账号功能本质是**一号多用**，便于公司/团队多人登录使用。

| | 主账号 | 子账号 |
|---|---|---|
| 定位 | 一般供公司负责人或主管使用 | 一般供公司员工使用 |
| 权限 | 可创建、登录、管理子账号；设置子账号之间是否可互看 | **各功能使用权限与主账号一致** |
| 额度 | — | **共享主账号套餐监控额度** |
| 密码 | — | **可以自行修改账号名称和密码** |
| 续费 | 可续费、升级、购买子账号 | **没有续费权限** |
| 归属 | — | 归属主账号管理，由主账号升级套餐获得配额并创建 |

**主账号对子账号的管理能力**：
- 创建、删减、激活或禁用子账号；
- 设置子账号之间是否可互看；
- 员工离职后可禁用/删除子账号，修改名称及登录密码，防数据外泄；
- 在【子账号】页面实时查看已激活子账号数量及套餐监控额度整体使用情况；
- 可登录子账号查看其关键词查询历史；
- 可手动设置各子账号之间监控项目是否互看。

> ⚠️ 【子账号可互看】**默认关闭**，需要时手动打开。
> 主账号登录子账号的方式：**子账号登录名 + 主账号密码**。

## 二、子账号配额

| 套餐 | 子账号数 | 可同时使用人数（含主账号） |
|---|---|---|
| 标准包年套餐 | 3 | 4 |
| 高级包年套餐 | 6 | 7 |
| VIP 包年套餐 | 10 | 11 |
| 包年套餐以下 | **无子账号** | 1 |

**增购子账号**：
- 登录主账号 →【个人中心】自助购买；
- 价格 = 子账号原价 × 子账号数 × (主账号剩余天数 / 套餐总天数)；
- 子账号使用期限与主账号**保持一致**。

**示例**：2025-03-28 购买包年套餐（2025.03.28–2026.03.28），3 月 31 日购买新子账号 → 该子账号期限为 2025.03.31–2026.03.28；单价 = 998 × 1 × 362/365 = **989**。

> ⚠️ 包年及以上套餐仅供**公司内部使用**。与陌生人拼团共享会有**数据泄露风险**。
> 建议：账号不共享、不外借；到个人中心绑定微信重新登录以提升安全性。

## 三、子账号创建与管理

### 创建（主账号 →【个人中心】→【子账号】→【创建子账号】）

**批量创建**：
- 选择所属部门 + 输入数量（套餐额度内，一次最多 **30 个**）；
- 登录名 = 部门首字母缩写 + 序号；
- 初始密码与登录名相同；
- 可一键复制或下载账号信息发给相关人员，登录后自行修改名称与密码。

**单个创建**：
- 必填：姓名、所属部门、登录账号、密码；
- 登录账号：6–30 位数字或字母（如 `abc001`）；
- 密码：6–30 位数字或字母（如 `123456`）。

> ⚠️ **一个子账号只支持一人同时在线**。若其他人同时登录同一子账号，已登录用户会被强制退出。

### 管理

| 功能 | 说明 |
|---|---|
| 所属部门管理 | 列表右上角按部门分类查看；下拉菜单「部门管理」可新建/修改部门；勾选后【移动到】可批量转移 |
| 登录时间监控 | 子账号超过 **15 天**未登录，【最后登录】字段会**标红**提醒，可考虑重新分配 |
| 批量删除 | 禁用或删除后的子账号**不再占用子账号数量额度**，可重新分配 |
| 账号导出 | 导出当前所有激活状态子账号的使用数据：账号基本信息、最后登录时间、登录次数、监控数量等 |

> ⚠️ **删除和创建子账号数量不能大于当前套餐的 3 倍限额**。如标准包年套餐（3 个子账号），则本月最多创建或删除 **9 个**子账号。

## 四、额度总览

### 监控额度（主账号与子账号**共享，不可指定分配**）

| 套餐 | 产品监控 | 关键词监控 | 店铺上新监控 |
|---|---|---|---|
| 包月套餐 | 100 | 500 | 50 |
| 标准包年套餐 | 100 | 500 | 50 |
| 高级包年套餐 | 300 | 1000 | 100 |
| VIP 包年套餐 | 500 | 2000 | 200 |
| 免费会员 | 0 | 0 | 0 |

查看已用/总额度：【产品监控】→【监控操作中心】。

### 导出额度

- 付费会员**每天可导出 50 次**（列表导出、导出明细分别计数）；
- 列表导出默认前 **2000** 条，闲时（**19:00–次日 08:00**）前 **3000** 条；
- 导出明细一次最多 **100** 个 ASIN；
- 关键词选品导出明细一次最多 **50** 个关键词，导出前 **2000** 条（闲时 3000 条）。

### 监控支持站点

美国、日本、英国、德国、法国、意大利、西班牙、加拿大、印度（共 **9 站**）。

## 五、数据更新频率（重要）

| 数据类型 | 更新频率 |
|---|---|
| 插件数据（价格、BSR、关键词排名等） | **实时**（查询时同步抓取亚马逊前台） |
| 销量数据 | **每日**更新一次，当日更新前一日 |
| 关键词数据 | **每月**更新一次，当月月初更新上月数据 |
| 关键词趋势选品 | **每周**更新一次，本周更新上周数据 |
| 关键词反查 | **每日滚动更新** |
| 监控数据（产品/关键词/店铺） | **每天**一次；关键词监控为滚动更新，各 ASIN 时间点不固定 |
| 店铺上新监控 | **一天**一次（全部抓取自亚马逊前台） |

## 六、账号常见问题

**Q：一个账号能同时登录几台设备？**
A：不论主账号还是子账号，**单个账号同时只支持在一个地点/一台设备**使用（浏览器也算一个设备）。
需要多设备/多地点 → 方案 a：错开时间或地点；方案 b：购买子账号或标准包年及以上套餐开通子账号。

**Q：主账号能跟踪子账号的操作记录吗？**
A：可以。子账号附属于主账号，主账号有管理权，可删除、禁用子账号，查看子账号历史记录。

**Q：不同亚马逊卖家账户用相同的卖家精灵插件和账号会产生关联吗？**
A：**不会**。卖家精灵是数据分析软件，本身无关联风险，且**不需要绑定任何卖家账号**，不会造成店铺关联。

**Q：子账号无法登录？**
A：常见 3 种情况，见 `/cn/help/child-account-login`。

## 七、插件常见问题

| 问题 | 解决 |
|---|---|
| 插件更新版本后如何升级 | 卸载旧版本后重新安装 |
| 插件卡顿 / 崩溃 | 多为电脑配置不足。a. 在插件设置开启「轻量版」自动关闭其他功能；b. 升级电脑（内存 16G+、CPU） |
| 插件无法正常登录/使用 | 参考 `/cn/help/how-to-resolve-extension-doesn't-work` 的 3 种方式；仍不行可加技术 QQ 远程协助 |
| 插件数据来源 | 亚马逊**没有开放任何官方 API**。插件数据一部分从前台抓取（BSR、价格、评分），另一部分是基于真实数据处理后的估算值（近 30 天销量、毛利率等） |

## 九、给子账号用户的实操建议

1. **先确认额度余量**：在【产品监控】-【监控操作中心】看已用/总额度，避免与其他同事争抢；
2. **导出有次数限制**：每天 50 次，且列表与明细分别计数 → 先过滤排序再导出，别浪费次数；
3. **利用闲时导出**：19:00–次日 08:00 可导前 3000 条；
4. **注意数据时效**：关键词库是月更、趋势选品是周更，不要当成实时数据汇报；
5. **单账号单设备**：不要与同事共用同一子账号登录，会被强制下线。
