## 一、三种「选品视角」的分工

| 功能 | 视角 | 逻辑 |
|---|---|---|
| 选产品 | **产品末端** | 基于已经成功的产品倒推 |
| 选市场 | **供应端** | 基于类目商品的热销与变化发现机会 |
| 关键词选品 | **需求端** | 直接反映买家真实需求，从用户端源头选品 |

三者互补，最终都需回到成本、供应链、竞争度做综合决策。

## 二、关键词选品（需求端初筛）

入口：`/v2/keyword-research`

### 推荐模式

| 模式 | 筛选条件 | 适合人群 |
|---|---|---|
| 热门市场 | 月搜索量 > 100000；月搜索量增长率 > 10.0% | 有运营经验、供应链与备货能力强的卖家，追求高单量 |
| 趋势市场 | 月搜索量近 3 个月增长值 > 10000；近 3 个月增长率 > 10.0% | 新入场 / 中小卖家，找潜力品类而非红海 |
| 类目飙升榜 | 月搜索量 > 10000；月搜索量增长率 > 10% | 想提前发现新品机会、关注季节性与节日性趋势 |
| 类目热搜榜 | 该类目下搜索量最大的关键词 | 从类目大盘找细分机会，判断竞争强度 |

### 自定义筛选示例

已有方向（如箱包）：输入核心词 `bag` → 选类目 → 设「月搜索量 > 1000」→ 按月搜索量 / 增长率 / 供需指数排序。

### 结果字段怎么读

| 字段 | 含义 | 读法 |
|---|---|---|
| 月搜索量 | 买家对该词的搜索需求 | 高 → 需求明确，但警惕竞争强；不能单独作为进入依据 |
| 月搜索量增长率 | 需求是否在增长 | 连续多月增长 → 趋势参考价值更强 |
| 近 3 个月增长值 | 近期新增需求规模 | 越大 → 近期新增需求越明显 |
| 商品数 | 市场供应情况 | 越多 → 竞争越充分；少 → 可能供应不足 |
| 供需指数 | **= 搜索量 / 商品数** | 越小代表竞争可能越大；搜索量大但商品数少 → 机会 |
| 历史趋势 | 长期搜索变化 | 每年固定月份上涨 → 季节性/节日性；持续上升 → 趋势型 |

> ⚠️ 不要只看搜索量。搜索量大只说明需求高，还要结合商品数、供需指数、PPC 竞价、点击集中度判断是否值得进入。

### 季节性与节日性选品

- **季节性**：选类目 + 设「市场周期」为旺季月份（如 `Clothing, Shoes & Jewelry` + `7-9 月旺季`）+ 输入核心词 `shoes`。
- **节日性**：输入节日名称 + 对应月份（如 `christmas`）。
- 关键：不要等搜索量已明显上涨才准备，否则错过产品开发、物流与 Listing 预热窗口。

### 实用技巧

| 技巧 | 规则 |
|---|---|
| 关键词对比 | 勾选 **2–5 个**关键词，横向比搜索量、ABA 排名等 |
| 查看历史数据 | 右侧历史趋势图标 → 近 **5 年**搜索趋势 + Google Trends + ABA 集中度 + PPC 竞价 |
| 导出明细 | 批量导出所选关键词近 **3 年各月**明细，一次最多 **50 个**关键词 |
| 导出 | 快速导出前 **2000** 条（闲时前 **3000** 条） |
| 付费会员 | 每天可导出 **50 次** |

## 三、ABA 数据选品 / 出单词反查

亚马逊品牌分析（**ABA** = Amazon Brand Analytics）仅面向**拥有品牌的卖家**开放，含五个模块：亚马逊关键词搜索、重复购买行为、市场篮子分析、商品比较和替代购买行为、人数统计。

卖家精灵的 **关键词趋势选品**（`/v2/keyword-research-weekly`）与 **出单词反查**（`/v2/aba/reverse/search`）数据来源于 ABA 的**亚马逊关键词搜索**模块。

**关键词趋势选品**特点：支持最近 **14 周（3 个月）**关键词数据，更能掌握买家需求实时变化。推荐模式：

| 模式 | 条件 | 含义 |
|---|---|---|
| 趋势市场 | 排名增长量近 4 周增长值 = 10000；排名增长率近 4 周 > 10% | 搜索排名持续增长 → 需求持续增长 |
| 搜索飙升市场 | 排名增长率近 1 周 > 50% | 需求非常急迫；季节性/节日性/萌芽潜力品 |
| 热门市场 | 搜索排名最大值 = 10000 | 需求最大的前 10000 个细分市场，竞争更激烈 |
| 潜力市场 | 搜索排名 10000–100000；增长率近 1 周 > 10% | 排名不错且在增长，竞争相对不激烈，适合中小卖家 |

**用点击集中度判断垄断**（实操案例）：
输入 `meat chopper` → 排名前 3 关键词的**点击集中度均 > 70%**（70%+ 点击集中在 3 款产品上）→ 换主词 `hamburger chopper` 结果类似 → 说明该类产品已被高度垄断。
再用市场分析报告验证：**商品集中度高达 71.1%**（头部前 10 产品占样本总销量 70%+）→ 结论：该细分市场垄断性过高。

## 四、关键词挖掘（以词拓词，建词库）

入口：`/v3/keyword-miner`

**核心逻辑**：定位关键词下的产品 → 挖掘与这些产品关联的关键词 → **层层下挖**（1→10→100→1000…）→ 构建庞大关键词库。

### 四大应用场景

#### 场景一：以词拓词 —— 构建精准关键词库

1. 输入核心主词（如 `phone stand`）→ 得初始词库（示例 5,685 个）；
2. **相关性筛选**：
   - 维度一（相关度）：**相关度 = 该关键词与查询词在亚马逊搜索结果第一页自然排名中同款竞品 ASIN 的比例**。建议过滤 `相关度 > 5` 且 `月搜索量 > 100`（示例得 296 个）。
   - 维度二（外观）：勾选「展示 10 条相关产品」，看 Top10 产品图。有同款 → 保留；无同款 → 删除（点关键词前数字序号即可删）。
3. 导出为 Excel 二次分析。

> **进阶：关键词有效性评估** — Listing 埋词权重优先级：**标题 > 五点描述 > 产品描述 > Search Terms > 其他**。

#### 场景二：词频分析 —— 关键词属性分类

把精准词（如 182 个）粘贴到【批量分析关键词】→ 展开**高频词**。词根后数字 = 出现频次，**频次越高权重越高**。
用途：发现垂直细分市场。如 `phone stand` 拓词的高频词可见 `tripod`（三脚架式）、`mount`（挂载式）、`ring`（圆环式）、`shower`（淋浴用）、`gooseneck`（鹅颈式）。

#### 场景三：广告投放 —— 筛有效关键词

- **SPR**（上首页所需单量）：按 **SPR 升序**排列 → 得上首页所需单量最少的词。
- **市场分析指标**：该词搜索结果**前 3 页（自然结果）**的产品平均价格、平均评分数、平均评分值。平均评分数低 → 新品进入壁垒不高。
- 其他竞争强度指标：点击集中度、PPC 竞价、广告竞品数。

#### 场景四：大词拓小词 —— 深挖长尾

1. 勾选「**词根匹配**」（老版「关键词静态挖掘」）→ 结果所有词均包含该词根；
2. 挖产品特性词：`yoga mat thick`、`large yoga mat`、`yoga mat non slip` → 月搜索量中等但**购买率较高**、**SPR 较低** → 前期主打词备选；
3. 叠加「单词个数」指标 → 找更易切入的长尾；
4. 挖细分市场：`yoga mat bag`、`yoga mat strap`、`yoga mat towel`、`foldable yoga mat`。

### 「挖掘关键词」vs「批量分析关键词」

| | 挖掘关键词 | 批量分析关键词 |
|---|---|---|
| 输入 | **1 个**核心词 | 最多 **200 个**词（粘贴） |
| 匹配 | 模糊匹配，会拓展新词 | 仅返回输入词，**不拓词** |
| 输出 | 几百–几千个候选词 | 补充指标：月搜索量、相关度、PPC 竞价、购买量、购买率、SPR、标题密度、AC 标识 |
| 场景 | 新品上架前建初始词库、竞品核心词拓词 | 对已筛出的 100–200 精准词批量补指标、横向对比 |

> 标准作业流程：**先挖掘拓展 → 后批量分析**。

## 五、关键词反查（单 ASIN 深挖）

入口：`/v3/keyword-reverse`

**查询内容**：目标 ASIN **近 30 天内进入过亚马逊前台搜索结果前 3 页的所有搜索流量词**，并提供流量词占比、推广类型、关键词排名、历史趋势。

### 两个查询入口

| 入口 | 用途 |
|---|---|
| **反查关键词** | 分析当前流量结构、关键词排名、广告推广情况（近 30 天） |
| **历史全量关键词导出** | 获取该 ASIN **历史累计查到的全量关键词**，通过【导出数据】获取 |

### 关键字段解读

| 字段 | 含义 | 注意 |
|---|---|---|
| 搜索流量词 | 让该 ASIN 进入搜索结果前 3 页、带来搜索曝光的词 | 反查竞品看覆盖；反查自己看亚马逊关联了哪些词 |
| 流量词类型 | 该 ASIN 在该词搜索结果中的曝光位置与推广方式 | 判断竞品重点推广词与广告类型（品牌广告、SP…） |
| 流量占比 | 该词带来的曝光量占比（如 `phone stand` = 8.52%） | 优先关注占比高的词 |
| 自然流量占比 / 广告流量占比 | 分别统计 | **两者相加可 > 100%**（同词既有自然又有广告曝光），属正常 |
| 历史趋势 | 不同月份关键词策略变化 | 判断竞品何时为旺季做准备 |

**历史趋势实操**：挂脖小风扇每年 3–4 月广告流量占比明显增加，结合 ASIN 透视的销量趋势可见 6–8 月为旺季 → 卖家在旺季前增加广告投放。

### 分析竞品（4 步）

1. **建初始词库**：收集多个同类 ASIN → 反查 → 找多个竞品共同覆盖的核心词、高流量占比词、精准词、差异长尾词（多竞品批量用【批量查询】跳转拓展流量词）；
2. **找主要流量词**：按流量占比降序 → 判断相关性 → 结合转化效果筛重点词 → 加入词库；
3. **掌握推广类型**：看核心词是否同时出现 HR 广告、视频广告、SP 广告；
4. **历史对比**：切换月份看自然/广告流量变化。

### 分析自己的产品（4 步）

1. **追踪关键词排名**：查自己 ASIN → 看每日关键词排名 → 调整 Listing 后持续追踪验证效果；
2. **补漏广告关键词**：找「已有流量占比但未投放广告或广告排名靠后」的相关词；
3. **检查关键词相关性**：新品反查看是否被收录大量不相关词 → 检查 Listing 文案准确性；也可对比该词前 10 名产品外观判断相关性；
4. **检查不相关词是否消耗广告预算**：导出 Excel 与亚马逊后台广告报表对比 → 及时否定。

### 与拓展流量词的分工

| 需求 | 用哪个 |
|---|---|
| 分析一个竞品当前从哪些词获流量 | 关键词反查 |
| 获取一个竞品历史累计的更多词 | 历史全量关键词导出 |
| 检查自己产品的关键词与流量来源 | 关键词反查 |
| 批量分析多个竞品 | 拓展流量词 |
| 一次看全部变体流量词 | 拓展流量词 |

## 六、拓展流量词（批量反查）

入口：`/v3/traffic/extend`

**原理同关键词反查**：抓取 ASIN 近 30 天进入搜索结果前 3 页的搜索流量词，每日滚动更新。核心优势：**批量查询**（一次最多 **20 个 ASIN**，空格分隔或从 txt/Excel 按列粘贴）+ **变体整合**。

### 三种拓词方式（检测到多变体时可选）

| 方式 | 逻辑 | 适用 |
|---|---|---|
| 使用畅销变体拓词 | 自动切到该 Listing **流量词最多**的变体 | 研究主要流量来源；不知哪个子体是引流款（**大多数竞品调研优先选这个**） |
| 使用全部变体拓词 | 全部变体流量词**合并去重** | 建完整词库；研究不同变体覆盖的差异化需求 |
| 使用当前变体拓词 | 只用输入的具体 ASIN | 只研究某个具体子体 |

### 核心指标

| 指标 | 怎么看 | 怎么用 |
|---|---|---|
| 流量占比 | 默认降序，优先看高流量词 | 快速了解竞品主要流量来源 |
| 相关 ASIN | 该词与本次哪些 ASIN 关联 | 区分「多数竞品共性词」与「少数竞品差异词」 |
| 月搜索趋势 | 需求随时间变化 | 判断季节词/节日词/新兴词的布局时间 |
| ABA 周排名 | 搜索热度表现 | 与月搜索量结合做第一轮流量筛选 |
| 月搜索量 | 月度需求规模 | 不能「越大越好」，需结合相关性、竞品覆盖、SPR |
| **SPR** | 辅助预估上首页所需单量 | 相对较低的可作为重点研究对象 |
| Top 10 产品图 | 该词自然结果前 10 商品图片 | 判断「这个词和我的产品到底相关不相关」 |

### 关键词清洗四步法

```
① 流量筛选：ABA 周排名 + 月搜索量 过滤无需求词（标准随类目容量调整）
② 相关性清洗：打开【展示前10产品图】，Top10 大量同类 → 保留；几乎无同类 → 删除
③ 竞争分层：结合 相关 ASIN + SPR + 月搜索趋势，判断是 共性词 / 差异词 / 长尾词 / 趋势词
④ 分库：拆成 Listing 核心词 / Listing 长尾词 / PPC 测试词 / 竞品监控词 / 潜力趋势词
```

### 典型场景

- **建多竞品词库**：一次输入多个核心竞品 ASIN，结果合并去重；
- **多变体不知查哪个**：只输入任一子 ASIN，选拓词方式；
- **找共性词**：某词被多数核心竞品覆盖 → 市场普遍竞争的流量入口（仍需看搜索量、Top10 集中度、自己是否覆盖、SPR）；
- **找差异词**：只被部分竞品覆盖但与自己高度相关的词 → 差异化机会（如 `waterproof hiking boots for women`）；
- **跨产品跨场景长尾**：同时查蓝牙耳机、运动耳机、降噪耳机 → 发现跨场景长尾；
- **季节词与趋势词**：结合月搜索趋势找提前布局窗口。

> ⚠️ **不建议未经筛选直接把拓词结果全部用于广告**。

## 七、流量词对比 与 关键词词库

- **流量词对比**（`/v3/keyword-comparison`）：比较多个竞品的**关键词覆盖情况**，了解不同竞品的流量来源差异。用于「查漏补缺」——对比自己与竞品的流量词覆盖。
- **关键词词库**（`/v3/keyword-store`）：把拓展/反查/挖掘的结果沉淀为可管理的资产，按用途筛选性价比更高的关键词。
- **关键词收录**（`/v2/keyword-checker`，免费）：查产品被亚马逊收录了哪些关键词。适合监控同类产品的关键词提升过程。
- **关键词转化率**（`/v3/keyword-conversion-rate`）、**实时查竞价**（`/v3/real-time-bidding`）：转化与竞价维度补充。

## 八、高频问题

**Q：关键词选品和产品选品有什么区别？**
A：关键词选品从买家搜索需求出发，判断某个关键词是否对应值得关注的细分市场（**前期发现机会**）；产品选品进一步判断具体商品是否值得开发或销售。

**Q：搜索量越大越值得进入？**
A：不一定。搜索量大说明需求大，也可能竞争更强。需同时看商品数、供需指数、PPC 竞价、点击集中度与历史趋势。

**Q：新手该先看哪个模式？**
A：通常先看**趋势市场**和**类目飙升榜**——搜索量未必最大，但增长趋势更明显，适合发现潜力机会。

**Q：关键词选品结果能直接作为最终决策吗？**
A：不建议。它适合初筛市场机会，进入市场前还需结合选市场工具以及利润、竞争、供应链、合规、库存、广告成本综合判断。
