# 05 · 流量与广告分析（查流量来源 · 广告洞察 · 关联流量 · 出单词反查）

> 官方快速入门：查流量来源 <https://www.sellersprite.com/v3/knowledge/feature/traffic-source-for-beginners> ｜ 广告洞察 <https://www.sellersprite.com/v3/knowledge/feature/ads-insights-for-beginners> ｜ 关联流量 <https://www.sellersprite.com/v3/knowledge/feature/relation-keyword-for-beginners>

## 一、查流量来源（Traffic Source）

入口：`/v3/reversing`

**定位**：分析目标关键词或 ASIN 的**搜索流量来源结构**——自然搜索、亚马逊推荐、PPC 广告三类入口分别覆盖了多少关键词。

### 两种查询方式

| 方式 | 输入 | 返回 | 适用 |
|---|---|---|---|
| **关键词查询** | 关键词 | 所选时间范围内进入该词搜索结果**前 3 页**的产品，及各 ASIN 的流量来源类型与流量词数量 | 从搜索词出发找竞品、建候选竞品清单 |
| **ASIN 查询** | ASIN | 该商品**及同组变体**的流量来源类型与流量词数量，默认按【全部流量词】降序 | 从商品出发看覆盖了哪些搜索入口 |

### 数据采集范围（关键前提）

数据来自亚马逊搜索结果**前 3 页**的产品。**未进入前 3 页的变体不会展示**，因此结果不一定包含该 Listing 的全部变体。
> 未展示某个变体 ≠ 该变体不存在，也不能判断它完全没有流量。阅读结果需同时确认**站点、时间范围、采集范围**。

### 字段解读

| 字段 | 含义 | 怎么用 |
|---|---|---|
| 搜索结果数 | 所选时间内进入过该词前 3 页的产品数量 | 比较同一关键词在不同周期的产品集合规模 |
| 流量来源 | 该 ASIN 出现的来源类型（自然搜索 / 亚马逊推荐 / PPC 广告） | 了解商品覆盖了哪些搜索入口 |
| 全部流量词 | 该 ASIN 流量词总数 | 初步比较关键词覆盖广度 |
| 自然搜索词 | 通过自然搜索结果获得展示的关键词数 | 找自然搜索覆盖较广的商品/变体 |
| SP 广告词 | 通过 SP 广告获得展示的关键词数 | 比较 SP 广告关键词覆盖 |
| 视频广告词 / 品牌广告词 | 对应广告类型的词数 | 观察视频/品牌广告搜索词覆盖 |
| AC 推荐词 / ER 推荐词 / 4 星推荐词 / HR 推荐词 | 细分推荐位词数 | 按列看数量，点开看具体词表（口径见页面【数据解释】） |

⚠️ **流量词数量反映的是关键词覆盖广度，不能直接换算成实际流量占比。**
自然搜索词多于 PPC 广告词，只能说明自然搜索覆盖的关键词**数量更多**，不能据此判断自然搜索的访问量、点击量或订单一定高于广告流量。

### 用「搜索结果数」判断市场流动性

- 搜索结果页每页约 40–60 个产品（含广告位、推荐位），某时点前 3 页通常 ≤ 200 个产品；
- 但本功能统计的是**一段时间内**进入过前 3 页的产品：
  - 搜索结果数**越多** → 这段时间有更多产品进入过前 3 页 → 流动性更大；
  - 搜索结果数**越少** → 前 3 页产品更稳定 → 其他产品进入难度可能更高。
- ⚠️ 不要把某个具体数字当作所有类目的统一标准，应结合不同关键词与不同时间段对比。

### 五大应用场景

1. **主关键词锁定核心竞品**：关键词查询 → 把持续出现在核心词前 3 页的 ASIN 纳入竞品分析范围；
2. **对比自然与广告关键词覆盖结构**：ASIN 查询 → 自然词明显更多 → 重点研究其自然词覆盖；广告词更多 → 分析其广告关键词结构与类型；
3. **观察搜索结果是否稳定**：看搜索结果数 + 切换时间范围，结合多个核心词判断（不要只看单个词、单个时点）；
4. **观察竞品运营策略变化**：切换时间段对比自然词/广告词数量变化（如广告词减少、自然词增加 → 可作为广告策略调整的**线索**，但**不能直接证明**投放下降）；
5. **找适合做商品定位广告的竞品变体**：自然词多的变体 → 优先研究；广告词多的变体 → 分析其广告布局。

## 二、广告洞察（Ads Insights）

入口：`/v3/ads-insights`

**定位**：抓取关键词搜索结果前 3 页中的 **SP 和 SBV 关键词广告**，反查 Listing 对应的广告活动、广告组与广告搜索词，结合搜索词特征**推测**竞品可能使用的投放词与匹配方式。

⚠️ **范围限制**：当前仅含 **SP 和 SBV 的关键词投放广告**，**不含商品投放**，**不含 SB、SD 广告**。

⚠️ **本质提醒**：展示的是**广告搜索词**，**不是**竞品后台直接设置的投放词。投放词与匹配方式靠搜索词规律**推测**，结论只能作为竞品广告研究的**参考**，不能当作竞品广告后台的完整还原。

### 分析层级

以 **Listing** 为对象，按 **广告活动 → 广告组 → 搜索词** 层级展示。
因此同一 Listing 下**无论输入哪个变体 ASIN，结果一致**（都是整个 Listing 的广告架构）。

### 操作步骤

1. 输入目标 ASIN → 立即查询；
2. 查看广告活动与广告组（示例：某产品共 **20 个广告活动、55 个广告组**，按历史→现在顺序展示）。
   - 一个广告组投多个变体时会按变体分别展示，所以页面广告组数量可能**多于后台实际数量**；
   - **相同颜色标识的广告组属于同一广告活动**；
3. 用【按周查看】/【按月查看】观察搜索词数量变化：趋势图圆点 = 该周期广告搜索词数量，**圆点越大词越多**；
   - 同一广告组不同周期圆点大小变化明显 → 搜索词数量波动大 → 可能出现在自动广告、手动广泛匹配、手动词组匹配中；
4. 点圆点进搜索词详情：看广告搜索词、展示的 ASIN、关键词 SP 广告排名、自然排名等；
   - 重点问两件事：**搜索词之间有没有共同词根？** **这些词与产品的相关度是否集中？**
5. 【导出】到 Excel 排序归类；【高频词】辅助判断搜索词主题集中度。

### 根据搜索词推测广告类型与匹配方式

| 搜索词特征 | 推测 |
|---|---|
| 围绕同一核心词根扩展（含错拼但词根一致），仅前后/中间加词 | **手动广告 · 广泛匹配** |
| 词间无明显规律，且出现大量弱相关词（如其他品类词、品牌词） | **自动广告 · 宽泛匹配** |
| 与产品高度相关，但彼此无明显词根规律（高频词显示多个词根并存） | **多个词组的广泛匹配** |
| 比较分散、无统一词根，但大多数仍与产品高度相关 | **自动广告 · 紧密匹配** |

**示例**：一组搜索词基本围绕 `toiletry bag` 扩展 → 推测投放词 `toiletry bag`、手动广告、广泛匹配。

### 判断匹配方式的三个角度 + 交叉验证

依次观察：
1. **看数量变化** — 词多或波动明显 → 可能拓词型投放；词少且长期稳定 → 可能集中于少量固定词；
2. **看共同词根** — 搜索词是否保持词组顺序、扩展词出现在什么位置（「词根」= 反复出现的核心词或词组）；
3. **看产品相关性** — 分散且无共同词根时，再区分是否仍围绕相近需求。

**交叉验证**：单个周期可能不足以呈现规律，选搜索词较多的周期与前后周期对照，并比较同一广告活动下不同变体的搜索词主题。

> ⚠️ **不要只根据一个特征直接下结论。** 品牌词、错误拼写、少量不相关词都只是**辅助线索**。
> 例如：多个搜索词保留完整的 `toiletry bag` 仅前后加描述词 → 可把**词组匹配**列为待验证可能；若词序打乱或核心词间插入其他词 → 更应考虑广泛匹配或多个投放词。
> 搜索词数量增减本身**不足以证明**竞品增加或减少了预算。

### 应用场景

- **整理竞品词库与待测试清单**：按产品类型/功能/使用场景归类搜索词 → 筛与自身相关的词形成待测清单 → 用**自己的**点击、转化、花费数据评估效果（**不直接照搬**竞品词表或推测的匹配方式）；
- **判断主推变体（线索）**：某变体在多个广告活动中持续出现 → 列为重点观察对象（**不能等同于**该变体销量最高或预算最多）；
- **跟踪不同阶段广告布局变化**：对比多周期的广告组、搜索词主题与变体分布。

## 三、关联流量（Relation Traffic）

入口：`/v3/relation-keyword`

**定位**：查看指定 ASIN 在亚马逊**商品详情页**中的关联曝光情况（近 **90 天**），分析关联流量入口、免费/付费结构，以及带来关联曝光的其他商品。

### 概念

**关联流量** = 买家通过商品详情页中的相关推荐、组合购买、商品广告等入口，发现并访问其他商品所形成的流量。

| 类型 | 含义 | 特点 |
|---|---|---|
| 免费关联流量 | 通过站内**非广告**关联推荐位置获得曝光 | 主要受商品相关性及消费者行为影响 |
| 付费关联流量 | 通过**广告**等付费推广获得关联位置曝光 | 可通过广告投放参与竞争 |

常见关联位置：
- **【看了又看】** → 分析与目标商品相似、具替代关系的**竞品**；
- **【组合购买】** → 发现功能互补、具搭配购买潜力的**产品**；
- **【商品广告】** → 分析商品广告带来的关联曝光及广告匹配商品的相关性。

> 关联推荐主要由亚马逊系统决定。可通过优化 Listing、调整广告投放、设计组合促销**尝试改善**，但**无法保证**商品出现在指定位置。

### 可查数据

- **关联 ASIN 数量**：曾在哪些其他商品详情页关联位置出现；
- **免费与付费关联流量占比**；
- **关联流量入口分布**（看了又看买 / 看了又看 / 组合购买 / 看了相关 / 更多相关 / 买了又买 / 商品广告 / 四星产品…）；
- **关联商品信息**：价格、评分星级等；
- **关联商品历史表现**：销量与排名趋势。

### 案例读法（ASIN `B09G2X39MK`，电热饭盒）

- 全部关联 **1,092** 个（近 90 天在 1,092 个关联位置对应的 ASIN 中获得过曝光）；
- 免费关联 **930** 个，占比 **85.16%** → 关联曝光以非广告推荐为主；
- 付费关联 **162** 个，占比 **14.84%** → 主要来自商品广告、四星产品；
- 主要免费入口：**【看了又看买】【看了又看】**；【组合购买】有少量关联。

**得出的判断**：
1. 免费关联占主导；
2. 相似商品关联突出 → 重点研究这些版块的相似竞品；
3. 付费关联集中在商品广告 → 查具体 ASIN 找投放参考；
4. 组合购买等入口仍有分析空间 → 评估搭配销售或产品线拓展。

⚠️ 关联数量反映的是**关联位置覆盖情况**，**不等于**实际点击量、访客数或订单量。

### 四个应用场景

| 场景 | 做法 |
|---|---|
| 查漏补缺，优化关联流量结构 | 看整体结构 → 找关联较少的入口 → 参考关联竞品的标题/图片/价格针对性优化 |
| 抢占竞品关联流量 | 在【看了又看】筛相似竞品 → 对比价格/评分/评论数 → 找适合投放商品定位广告的 ASIN（自身有价格或评分优势时） |
| 扩充产品线 | 看【组合购买】找功能互补商品（如直播补光灯 → 绿幕、麦克风、直播支架） |
| 检查商品广告匹配 | 看【商品广告】版块，判断广告出现的商品页与自身产品是否相关 |

> 关联商品历史表现：点列表中带下划线的数字可看对应商品的历史销量与排名趋势。

## 四、出单词反查

入口：`/v2/aba/reverse/search`

反查**核心出单词**，数据源为 ABA（Amazon Brand Analytics）的**亚马逊关键词搜索**模块。配合关键词趋势选品使用，判断哪些词真正带来成交。

## 五、流量分析的整体用法

```
关键词选品 / ABA 选品      → 先确定候选关键词市场
        ↓
关键词挖掘 + 拓展流量词     → 建立候选词库
        ↓
关键词反查                 → 单竞品深挖：出单词、流量占比、推广类型
        ↓
查流量来源                 → 看自然/推荐/广告三入口的词覆盖结构
        ↓
广告洞察                   → 拆广告活动/广告组/搜索词，推测投放打法
        ↓
关联流量                   → 找关联入口缺口、投放对象、互补品
        ↓
关键词监控 + 产品监控        → 持续追踪排名与竞品动作
```

**输出纪律**：广告洞察的匹配方式、查流量来源的策略变化、关联流量的意图，都属**推测或线索**，务必标注为「待验证假设」。
